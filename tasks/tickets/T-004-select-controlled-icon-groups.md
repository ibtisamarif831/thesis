# T-004: Select controlled icon groups and matched pairs

Status: Todo  
Priority: High  
Depends on: T-002, T-003

## Goal

Create qualitative stimulus groups whose icons are similar overall but differ in one or two target visual properties.

## Acceptance criteria

- Review approximately 20 candidates per selected family feature.
- Shortlist approximately 10 icons per intended group, recording whether “10” means per family or total.
- Include visually close pairs and visually distant controls.
- Record the target differing feature(s) and the other properties held approximately constant.
- Produce a review table with icon IDs, images, scores, pair/group membership, and reviewer notes.
