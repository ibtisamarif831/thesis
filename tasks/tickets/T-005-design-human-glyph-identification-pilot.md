# T-005: Design a pilot human glyph-identification study

Status: Todo  
Priority: High  
Depends on: T-004

## Goal

Decide how to measure identification, interpretation, similarity, and confusability in participants.

## Acceptance criteria

- Define an identification task (free label, multiple choice, or both).
- Record confidence for each answer.
- Define a similarity/confusability task for selected pairs.
- Add an optional short explanation prompt: which visual details influenced the answer?
- Specify participant instructions, trial order/randomization, stopping rules, and pilot size.
- Keep semantic interpretation as a human outcome, not as a computer-vision feature.
